Sparklis, vendored for the SOSA/SSN Usage Observatory
=====================================================

Sparklis: a query builder in natural language for SPARQL endpoints, by Sébastien Ferré
(IRISA, Université de Rennes). https://github.com/sebferre/sparklis
Licence: Apache License 2.0 (LICENSE, copied from the repository).
Citation: Sébastien Ferré, "Sparklis: An expressive query builder for SPARQL endpoints with
guidance in natural language", Semantic Web 8(3): 405-418, 2017.

The application opens Sparklis with the same settings in its address (proxy_url=,
logging=false, short-permalink=false) since Sparklis prefers its built-in defaults to the
HTML ones when an argument is missing. Its hit counter still asks for log/log.php once at
start, before it reads that argument: a request to this site only, answered 404.

Not vendored: the PHP logger (webapp/log/), the examples page and the release notes. The page
still loads, as upstream, jQuery 2.2.4, Bootstrap 3.3.6, YASGUI 2.6.1 and the Google Charts
loader from their CDNs.
